Les notions minimales

ÉlémentRôle
DATADéclare une variable. Le préfixe lv_ désigne une variable locale (local variable).
CONCATENATE a b c INTO resultatAssemble les chaînes a, b et c sans aucun séparateur.
* en début de ligneLigne de commentaire, ignorée à l'exécution.

Exemple

* Assemble deux morceaux de texte
DATA lv_p1 TYPE string VALUE 'abc'.
DATA lv_p2 TYPE string VALUE 'def'.
CONCATENATE lv_p1 lv_p2 INTO DATA(lv_resultat).

Après exécution, lv_resultat contient abcdef : les deux morceaux sont collés l'un à l'autre, sans espace entre eux.

À surveiller

Les développeurs découpent parfois les secrets en plusieurs morceaux pour qu'une recherche grep sur la valeur complète ne donne rien. Lorsque vous voyez plusieurs variables lv_ aux valeurs courtes assemblées par un CONCATENATE, reconstituez le résultat en recollant les morceaux dans l'ordre indiqué par l'instruction.
