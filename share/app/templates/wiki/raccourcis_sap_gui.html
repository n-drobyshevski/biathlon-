Un fichier texte

Un raccourci SAP GUI (extension .sap) est un simple fichier texte au format INI. Il se lit avec n'importe quel éditeur de texte, sans outil particulier.

[System]
Name=PRD
Description=Production DécaFlop
Client=100

[User]
Name=EXEMPLE
Password=ZXhhbXBsZQ==

[Function]
Command=SESSION_MANAGER

Le champ Password

Lorsque la case « Enregistrer le mot de passe » est cochée à la création du raccourci, SAP GUI écrit la ligne Password= en Base64.

Ce n'est pas du chiffrement : c'est un simple encodage. Il n'y a aucune clé et il se défait en une commande. Toute personne qui peut lire le fichier peut lire le mot de passe.

ZXhhbXBsZQ==example

Où se trouvent ces fichiers

Les raccourcis .sap traînent là où on ne les cherche pas :

  • les sauvegardes de postes portables ;
  • les profils itinérants (roaming profiles) ;
  • les dossiers de téléchargements et les partages de service.

Pensez à les inclure dans toute recherche de secrets sur un poste ou dans une sauvegarde.
